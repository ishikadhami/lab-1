LAB 1 — Question 2: Custom Module Creation & Reusability

Requirements:
• Create a custom module such as isEven.
• Export functionality using module.exports.
• Import the module into another file using require().
• Demonstrate module reusability with proper examples.

File: isEven.js
------------------------------------------------------------
function isEven(number) {
    return number % 2 === 0;
}
module.exports = isEven;
------------------------------------------------------------

File: app.js
------------------------------------------------------------
const isEven = require("./isEven");
const numbers = [2, 5, 8, 11, 14];

numbers.forEach((number) => {
    if (isEven(number)) {
        console.log(number + " is even");
    } else {
        console.log(number + " is odd");
    }
});
------------------------------------------------------------

How to run / test:
• Create a folder and save both files in the same folder.
• Open the terminal in that folder.
• Run: node app.js
• Expected output: 
  2 is even
  5 is odd
  8 is even
  11 is odd
  14 is even
