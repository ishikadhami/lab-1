LAB 1 — Question 4: File Manager using fs Module
Requirements
• Implement file operations such as Create File, Read File, Update File and Delete File.
• Use methods such as writeFile(), readFile(), appendFile() and unlink().
• Display success/error messages in the terminal.
• Handle missing file errors gracefully.

File: fileManager.js
const fs = require("fs");
const fileName = "sample.txt";

// CREATE FILE
fs.writeFile(fileName, "This is the original file content.\n", (err) => {
 if (err) {
 console.log("Error creating file:", err.message);
 return;
 }
 console.log("File created successfully.");

 // READ FILE
 fs.readFile(fileName, "utf8", (err, data) => {
 if (err) {
 console.log("Error reading file:", err.message);
 return;
 }
 console.log("File content:");
 console.log(data);

 // UPDATE FILE
 fs.appendFile(fileName, "This line was added during update.\n", (err) => {
 if (err) {
 console.log("Error updating file:", err.message);
 return;
 }
 console.log("File updated successfully.");

 // READ UPDATED FILE
 fs.readFile(fileName, "utf8", (err, updatedData) => {
 if (err) {
 console.log("Error reading updated file:", err.message);
 return;
 }
 console.log("Updated file content:");
 console.log(updatedData);

 // DELETE FILE
 fs.unlink(fileName, (err) => {
 if (err) {
 if (err.code === "ENOENT") {
 console.log("Error: File does not exist.");
 } else {
 console.log("Error deleting file:", err.message);
 }
 return;
 }
 console.log("File deleted successfully.");
 });
 });
 });
 });
});

How to run / test
• Save the code as fileManager.js.
• Open the terminal in the same folder.
• Run: node fileManager.js
• The program creates sample.txt, reads it, updates it, reads the updated content and finally deletes it.
• Missing-file errors are handled using the error code ENOENT.
